## Explicit unsupported data areas

- Productivity: no persisted productivity score/KPI source exists; UI returns N/A.
- Task/project contribution: no task/project models exist.
- Engagement/login frequency: no login/activity event model exists.
- KPI radar: performance reviews contain a scalar rating and goals, but no comparable skill/KPI dimension scores.
- Actual-versus-expected scheduled hours: attendance rows and finalized payroll snapshots do not provide a reliable full scheduled-workday baseline for every date; no synthetic baseline is inserted.

## Completion statement

This delivery contains substantial implementation and passing automated checks, but it is **not certified 100% complete or production-ready**. The Vite build and live MongoDB/SMTP/Gemini/Cloudinary/Inngest/browser integrations remain unverified for the specific environment because the required Linux optional dependency and provider credentials were unavailable.
